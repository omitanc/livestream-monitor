# LiveStream Monitor

自分のYouTube Liveを視聴側から監視し、映像停止・黒画面・ライブ位置からの遅延・監視PCの停止を検知する、macOS・Windows向けアプリの開発リポジトリです。

現在は要件整理段階です。最初の実装対象はYouTube Liveに限定します。視聴映像は専用アプリ内に表示する方針です。設計上の前提と未決事項は [docs/project-brief.md](docs/project-brief.md) を参照してください。

## 開発の最初の確認事項

1. macOS・Windowsのアプリ内でYouTube Liveを安定して視聴できるか。
2. 再生中、画面の最小化中、ページ再読み込み後に映像領域を取得できるか。
3. デジタル時計、黒画面、映像停止、ライブ位置からの遅延を区別できるか。
4. PCの警報音と外部通知が実機で届くか。

実装言語、アプリ基盤、通知サービスは検証して決定します。秘密情報・APIキー・ping URLはリポジトリに保存しません。
